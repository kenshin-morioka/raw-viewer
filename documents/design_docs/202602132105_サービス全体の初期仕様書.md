# RAW Binary Viewer 設計書

---

# 1. 概要

## 目的

写真のRAWファイル（ARW / CR2 / NEF など）のバイナリ内容を、TUI上で閲覧・簡易解析できるツールをRust + ratatuiで開発する。

本ツールは以下を目的とする：

- RAWファイルのhex表示
- ASCII表示
- 簡易解析（TIFF検出など）
- 大容量ファイルへの拡張性

---

## 実行環境

- Rust
- ratatui
- crossterm
- wezterm（一般的なterminal互換）

---

## MVP機能

- ファイルロード
- hex viewer
- ASCII表示
- スクロール
- ファイル基本情報表示

---

# 2. アーキテクチャ

Elm Architectureを採用する。

```text
INPUT(Event)
↓
UPDATE(State Mutation)
↓
RENDER(UI)
```

---

## レイヤ分離

UI Layer

- 描画のみ
- 状態変更禁止

Application Layer

- App State
- Event handling

Domain Layer

- RAW解析
- hex変換

Infrastructure Layer

- file IO

# 4. State設計

## AppState

```rust
pub struct AppState {
    pub data: Vec<u8>,
    pub cursor_offset: usize,
    pub scroll_offset: usize,
    pub file_size: usize,
}
```

## 原理原則

- UIはstateを読むだけ

- updateがstateを変更

- parserはstateを直接変更しない

# 5. Eventモデル

```rust
pub enum AppEvent {
    Quit,
    MoveUp,
    MoveDown,
    PageUp,
    PageDown,
}
```

# 6. Event Mapping

```text
q       -> Quit
Up      -> MoveUp
Down    -> MoveDown
PgUp    -> PageUp
PgDown  -> PageDown
```

# 7. Update Layer

```rust
pub fn update(state: &mut AppState, event: AppEvent)
```

責務：

- state変更のみ

- 描画禁止

- IO禁止
